# Urban Bites – Restaurant Website

## Project Overview

Urban Bites is a restaurant website developed using HTML and CSS. It provides visitors with an attractive and user-friendly interface to explore restaurant information, menu items, gallery images and contact details.

This project was developed as part of my personal web development portfolio to practise front-end website development.

## Technologies Used

- HTML5
- CSS3

## Main Features

- Restaurant homepage and introduction
- Navigation menu
- Restaurant menu section
- Food gallery
- About section
- Contact section
- Responsive layout

## Project Structure

```text
urban-bites-website/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

This is a demonstration project created for learning and portfolio purposes.
